# Multi-Video Processing Using a Dual Chaotic Map

A final year student project that demonstrates a Python desktop interface for selecting and previewing videos, then processing video frames with a key generated from a dual chaotic-map approach.

## Features

- Select video files for preview
- Enter a secret key and map parameters
- Process video frames using XOR
- Display basic processing and image-analysis metrics

## Built with

- Python
- Tkinter
- OpenCV
- NumPy
- Pillow

## Requirements

- Python 3
- OpenCV (`opencv-python`)
- NumPy
- Pillow
